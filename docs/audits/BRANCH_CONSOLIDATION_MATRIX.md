## Evidence method

Each remote tip was resolved to a full SHA. The inventory ran `git merge-base --is-ancestor`, `git rev-list --left-right --count`, `git cherry`, merge-base source file comparisons, and `git merge-tree --write-tree --name-only`. Clean merge trees were compared with the starting main tree. The inventory does not change remote refs or the working checkout. For historical source differences, the existing [PR ledger](../plans/PR-CONSOLIDATION-2026-11-17.md) and [archive index](../archive/specs-historical/README.md) were cross-checked against current file paths, behavior, test symbols and source history.

`git cherry` ignores merge commits and detects single-patch equivalence, not squash equivalence. Therefore a non-equivalent commit is not automatically missing work. Conversely, the erasure branch has a patch-equivalent commit but still conflicts with subsequent edits. No branch was discarded merely because of its age.

GitHub returned an empty repository ruleset collection. Reading legacy branch protection returned HTTP 403 (`Resource not accessible by integration`), so protection settings are **unverified**, not absent. Normal merge APIs and repository gates must still enforce them. The CLI has no GitHub login; provider reads used the connected GitHub API.
