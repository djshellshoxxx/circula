# Hosted platform policies (GOV-026)

Each policy is dated and versioned in its header (`Version:` and `Date:` lines; `scripts/check-hygiene.sh` checks them).
Change history is in git. A material change is announced to network administrators before it takes effect: at least 14
days for an adverse change (DEC-025), using the announcement flow in the admin guide. These are drafts until counsel has
reviewed them and the operator publishes them with a launch date (release gate).
