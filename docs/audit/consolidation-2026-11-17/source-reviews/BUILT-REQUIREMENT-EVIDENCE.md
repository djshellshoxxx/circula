# Review of built requirements without test citations

Review date: 2026-11-19 UTC. Source baseline: `244e1356201e6477eab4694d82947f2058f3b0d8`. This review examines the **19 requirements declared built without a test citation** in that source's committed traceability inventory. It changes evidence notes and one overstated status; it does not change runtime behavior, acceptance criteria or the generated inventory.

## Findings and limits

Three requirements have direct, existing automated assertions whose links were missing from their status notes: **ARC-005, ARC-014 and DAT-017**. Their notes now name those tests and state what they actually check. No test was added merely to obtain a citation.

**SEC-031 changes from built to partial.** Its security-policy document exists, but it contains contact/key placeholders and an explicit request to confirm that private vulnerability reporting is enabled. An owner-approved contact channel is a stated acceptance criterion. This review neither supplies that approval nor changes the reporting configuration.

The other 15 original rows retain their status. The missing **Tests** cells have different causes: some requirements have executable shell release checks, some rely on inspection, and others lack a particular automated or manual acceptance assertion. Related tests below are distinguished from full requirement evidence. Reducing the citation count to zero would misrepresent those differences.

A separate generator preview of these documentation changes resolved **531 IDs, 15 built requirements without a test citation, zero unknown IDs and zero duplicates**. The reduction from 19 is three repaired citation links plus the honest status correction for SEC-031. The committed `docs/TRACEABILITY.md` was not edited; the parent integration regenerates it once for the combined source.

**Execution boundary:** test functions, scripts and assertions were read, not rerun by this review. A generator preview checks citation resolution only. It is not a product test, release smoke, deployment drill, accessibility assessment or owner decision. Current-head execution receipts remain separate from this source review.
