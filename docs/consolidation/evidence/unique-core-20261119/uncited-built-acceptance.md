## Boundaries that should remain explicit

- The strongest small automated evidence opportunities are DAT-001's production default generator and DAT-002's substitution seam. Existing generated-ID usage and deterministic fixtures are implementation evidence, not direct assertions of those contracts.
- The broader automatically executable gap is **qualification of a packaged release under both deployment configurations and on the required native targets**. Existing service tests, cross-build scripts and CI configuration are not retained execution receipts for that qualification.
- The session inventory deliberately uses an independent persisted 64-character selector, described in spec 07's account-session contract; spec 06 also describes session storage as a hashed credential identity. These are documented exceptions/contract distinctions. Broad DAT-001/002 wording should not trigger a new identity migration during consolidation.
- VIS-012's historical deferred list and GOV-017's stale HTML route locator are documentation/evidence precision issues, not newly discovered missing behavior. No statuses were changed by this audit.
