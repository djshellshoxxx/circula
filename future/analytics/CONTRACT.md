# Isolated analytics contract

Construct `DashboardService` explicitly with a fresh authorized `Source`, injected clock, fixed network IANA zone, k >= 5 and fixed aggregate granularity (`month` default, or `week`). DormantDays defaults to30 and otherwise must be1–365. There is no registration, database connection, migration, cache or worker.

`Source.Read(ctx, actor, admin, cutoff)` must authorize current network membership and, when admin=true, analytics-admin privilege inside the same read-only transaction as the data. Return all required immutable posting facts strictly before cutoff and ledger-derived balance stock exactly at cutoff, including relevant originals for reversals. Completed means an immutable posting exists, not a mutable current status. Include grant/adjustment events for own-balance reconstruction. Account system classification must be immutable; all posting parties and visible offers must resolve to explicit network-scoped balance/account facts. No client-supplied snapshot is accepted. Inputs are capped; an oversized/inconsistent source fails closed instead of serving a partial aggregate.

The unregistered Handler supports authenticated GET only, `view=admin|own`, `period=week|month`, `count=1..12` and `format=json|html|csv`. Unknown/duplicate/malformed query fields and arbitrary from/to/member filters are rejected. X-Network, when supplied, must be singular and match the session scope. Responses are no-store with a restrictive CSP. Each aggregate request reauthorizes through the source. Formats contain only privacy-filtered aggregates or the authenticated member's own trend. Raw personal export is not offered.

JSON monetary values are decimal strings, never IEEE-754 numbers. HTML/CSV show exact integer minor units with decimal scale and named time zone. Admin JSON includes flow, stock and dormant metrics; admin CSV is the flow table. Own JSON/HTML/CSV includes historical opening/closing and posting/no-posting state. The shared host-authenticated CLI supports `admin week|month COUNT` (flow CSV), `admin-json week|month COUNT` (full release JSON), and `own week|month COUNT` (own JSON). It reads no credentials and opens no independent store.

One host-configured aggregate granularity per network prevents caller-selected overlapping weekly/monthly slices. Every admin release is cut at the most recently closed calendar boundary. Source revision is never published; the output fingerprint includes only released values. Hidden/global revision changes do not affect it. The actual producer must preserve immutable published releases at the same cutoff across restarts/corrections; deploy a reviewed release/query-budget policy before integration. This module does not claim differential privacy or anonymity against all external knowledge.

No money-moving API, reputation score, sanction, automatic acceptance or raw member export exists. Actual core routes/contracts/CLI wiring, database recovery and manual accessibility remain separate qualification. Integration HOLD remains.

The HTTP transport rejects queries larger than 2,048 bytes before host authentication can parse them. This bounds query parsing only; the source must still enforce request deadlines and bounded historical reads. Diagnostic benchmarks include source-snapshot validation, 12-period calculation and release fingerprinting; fixture construction is outside the timer.
