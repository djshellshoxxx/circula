# Future adapter contract — not active in Circula

Construct `New(Config{Enabled:true, PublicOrigin:"https://host.example", BasePath:"/community/", Find:"/community/listings", Trade:"/community/transactions/new", Balance:"/community/balance", Inbox:"/community/notifications"})` only after single-feature integration approval. The zero-value config serves 404. Mount the handler explicitly for its exact worker/manifest/static/install routes; delegate all other paths to the existing application. Root mounting, actual application paths and configuration are not implemented here.

Insert the manifest link, fingerprinted `StylePath` and `ClientPath`, and `<meta name="circula-pwa" content="/community/">` only when the feature is enabled. `BasePath` is a strict same-origin path ending in `/`; use one stable scope and identity per deployment path. HTTP is allowed only for explicitly opted-in loopback tests. Behind a reverse proxy, supply a trusted canonical origin and preserve the matching Host; never trust arbitrary forwarding headers to construct it.

The proposed CSP constant adds self-only manifest/worker/connect directives to the harness. Merge these carefully with Circula's existing CSP rather than replacing it wholesale. Keep authenticated HTML, API, exports and receipts `Cache-Control: no-store`. Existing un-fingerprinted application assets must NOT be added to the public manifest. Build metadata, MIME, filenames and contents are verified before bundle construction; only bundled immutable public bytes are eligible for precaching.

Wrap private rendered views in `[data-private]`. Keep the native POST/CSRF sign-out form **outside** that wrapper: the client locks/scrubs private content synchronously on submit but must not delete CSRF controls before the browser serializes the sign-out form. The existing server remains responsible for CSRF and actual session revocation. The adapter can additionally dispatch `circula:session-ended` after successful revocation. BroadcastChannel tells other open tabs only to lock; it carries no account data. A failed sign-out network request locks the local display but does not claim the server session was revoked.

On pagehide/visibility loss the private DOM is destroyed. Resume/restored pages reload from the authenticated server; old private DOM is never unhidden. This deliberately abandons unfinished form state rather than retaining sensitive trade drafts locally. Do not add autosubmit on reconnect or restore. OS app-switcher snapshots, browser BFCache behavior and mobile resume still need actual platform qualification.

The synthetic `cmd/demo` is loopback-only and uses trivial A/B cookies solely as fixtures. It is not an authentication implementation and must never be mounted as production routes. No core transaction/session/API contract is implemented by it. Production adapter qualification must include the real authorization, CSRF, tenant, idempotency and full ledger regression suites.

There are no migrations, persistent member preferences or private data stores in this module. Disable by omitting registration/links and route mounting. A future disable adapter should unregister this scope and delete only its `circula-pwa-<scope-hash>-` cache namespace; it must not erase unrelated origin caches. Existing installed workers can remain active until browser lifecycle cleanup, so disabling/decommission behavior requires browser acceptance before release.

Precache bounds: the build records each asset's exact byte size; the Go loader refuses assets over 1 MiB, catalogs over 32 assets, and any size/MIME/hash/name mismatch, and the worker reads each response through a streaming bound before hashing and storing it. Host applications must keep assets served at `static/` small and public (`Cache-Control: public`) or the worker install will fail closed. The client's private-view lifecycle is independent of service-worker and BroadcastChannel support; keep the client script included even where workers are unavailable.
