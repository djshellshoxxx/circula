# Project Overview

**Status: Draft**

## Purpose

Circula explores software for voluntary community exchange using mutual credit. Members can provide value, receive a positive account entry, and use their balance to obtain value from other members under network-defined rules.

## Project principles

- Voluntary association and exchange
- Local network governance within platform-wide ledger invariants
- Balanced, traceable accounting
- Data portability and self-hosting as design goals
- Privacy minimization and clear member consent
- Interoperability only by agreement among networks

## Current status

The repository currently contains draft specifications and idea lists, not an implemented service. Read the [repository README](../README.md) and the [specifications index](../docs/specs/README.md) for source documents.

## What Circula is not

Circula does not guarantee acceptance or fulfillment, promise redemption for national currency, assign universal value to credits, or provide legal, tax, or financial advice. It is not inherently a cryptocurrency or blockchain project.
