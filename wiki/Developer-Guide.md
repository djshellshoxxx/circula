# Developer Guide

**Status: Framework; application implementation has not started.**

The repository currently contains product specifications and planning documents. No language, framework, database, or build process is selected by the foundational baseline.

## Before contributing code

- Read the [specifications index](../docs/specs/README.md).
- Treat the domain model as authoritative for accounting behavior.
- Do not infer implementation status from a requirement.
- Add or update tests for ledger invariants, authorization, idempotency, disputes, migration, accessibility, export, and restore.
- Keep decisions technology-neutral until the project owner records an ADR or updates the decision register.
