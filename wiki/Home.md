# Circula Wiki

**Status: Framework / draft. Circula is currently in the documentation and design stage; this Wiki is not a guide to an available application.**

Circula is an open-source-capable project exploring software for community mutual-credit networks. It aims to help communities coordinate voluntary exchange while keeping accounting understandable, balanced, and governed by network members.

A Circula balance is an accounting position under a network’s rules. It is not presumed to be cryptocurrency, redeemable money, or a guarantee that another member will accept or fulfill an exchange.
