# Security, Privacy, and Data

**Status: Draft framework; not a security certification or compliance claim.**

This page will become a user and operator guide after implementation. It should explain:

- Authentication, role permissions, account recovery, and session safety
- Which profile fields members, administrators, reviewers, and platform operators can see
- How dispute evidence is restricted
- What appears in audit records and logs
- How exports work and who can create them
- How backups are protected, restored, and reconciled
- How to report abuse or a suspected account compromise

The project’s baseline is to collect only necessary data, scope access by network and role, audit privileged actions, and avoid putting secrets or unnecessary personal data in logs. The current specification does not claim anonymity, legal compliance, or cryptographic guarantees. See the [security and privacy spec](../docs/specs/09-security-privacy.md).
