# Deployment and Operations

**Status: Framework; hosting choices are unresolved.**

The project has not yet selected whether its first release will be hosted, self-hosted, or both. This page will document verified deployment steps after the reference model is selected.

## Planned operator documentation

- Supported environments and prerequisites
- Configuration and secret handling
- Deployment, upgrade, and migration procedures
- Backups, restore, and reconciliation
- Monitoring, outage response, and recovery
- Support responsibilities and escalation routes
- Network export and service closure

Do not treat self-hosting as automatic security or independence. Operators need a maintained release process, protected backups, and a tested recovery plan. See the [deployment specification](../docs/specs/11-deployment-operations.md).
