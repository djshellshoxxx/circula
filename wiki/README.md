# Circula Wiki framework

This directory contains Markdown source for the planned GitHub Wiki. GitHub Wikis are separate from the main repository; keeping source here makes it reviewable and versioned with the specifications. This is a framework and draft reference, not a manual for a working application.

## Page status convention

- **Framework:** page structure and authoritative sources are established; product behavior may not exist.
- **Draft:** content is proposed and requires review.
- **Verified:** instructions have been checked against a released application version.

Until Circula has a runnable release, user workflow pages describe intended behavior from draft specifications and MUST say so. Do not present a planned requirement as an implemented feature.

## Publishing and maintenance

When the project owner is ready to publish the Wiki, copy these page files into the repository’s GitHub Wiki. Keep the sidebar and footer with the pages. Update pages from their linked authoritative specifications; do not let the Wiki silently diverge from accounting or security rules. For source-of-truth files, see ../docs/specs/README.md.
