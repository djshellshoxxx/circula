# Network Administrator Guide

**Status: Framework; administration features are draft requirements, not implemented.**

This page will document verified setup steps after Circula has a release. The intended administrator responsibilities are:

- Establish network name, unit label, admission rules, and administrator succession.
- Configure participation, credit limits, listing visibility, transaction acceptance, and dispute policies.
- Admit, suspend, reinstate, and offboard members with attributable actions.
- Announce and record policy changes.
- Appoint reviewers and manage conflicts of interest.
- Authorize adjustments only through explicit, traceable procedures.
- Export data, plan backups, and document closure.

Administrators govern a network within platform-wide invariants: no unbalanced completed trades, no silent ledger edits, and no cross-network posting. See [[Governance]] and the [governance specification](../docs/specs/10-governance-operations.md).
