# Circula

Circula is software for running community mutual-credit networks. Members of a network provide goods or services to one another and record each trade in a shared ledger: the member who provided value is credited, the member who received it is debited by the same amount, and the sum of all balances in a network is always zero. Each network sets its own participation, credit-limit, dispute, and governance rules within the invariants the software enforces.

Circula is software for operating such a network. It does not guarantee that credits have monetary value or that members will accept them; a credit is an accounting unit defined by the network that uses it.
