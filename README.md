# Circula

Circula is a planned open-source-capable software platform for community mutual-credit networks. Members provide goods or services, earn a positive balance by providing value, and use those credits to obtain value from other members. A transaction moves equal and opposite amounts between the participating accounts. Each network sets its own participation, credit-limit, dispute and governance rules.

## Current contents

**This repository has no application code yet.** It contains one file, [`prompts/create-foundational-specs.md`](prompts/create-foundational-specs.md). That file is a prompt to give a coding agent so it writes the foundational specifications as separate Markdown documents in this repository.

There is nothing to install, build or run yet.

## Contributing

Specifications are the first deliverable. Once they exist, they should govern implementation. Record decisions with their reasons, and keep the security and privacy requirements in the specs rather than in code comments.
