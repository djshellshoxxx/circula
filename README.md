# Circula

Software for running community **mutual-credit networks**: members earn a positive balance by providing goods or services and spend it with other members; every trade posts equal and opposite amounts. Each network sets its own participation, credit-limit, dispute and governance rules.

The credit unit is an accounting unit. Circula does not guarantee that credits have monetary value or that members will accept them, and by design offers no redemption, cash-out or interest.
