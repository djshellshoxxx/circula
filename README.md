# Circula

Circula is an open-source-capable platform for operating community mutual-credit networks. It is intended to help network members discover offers and requests, agree on exchanges, and maintain a transparent shared accounting record.

A Circula balance is an accounting position within its network. The project does not guarantee that credits have monetary value, that members will accept them, or that they are redeemable for national currency.
